# 社区审核生产 HTTP 与持久核对

日期：2026-11-03。对应 API-M08 / ADM-16。后端生产业务和24项迁移保持，本轮扩展管理 HTTP 客户端及数据库后置断言；契约仍为 OpenAPI 1.51.1 / 143 操作。

真实 HTTP 使用 Web 生产读取、准备和审核命令函数、编译 Nest 与独立临时 PostgreSQL。配置角色按入口/审核 grant 管理社区，不依赖固定商家或系统管理员角色键。作者通过真实 API 创建并编辑动态；审核、公开可见性及独立评论分页均通过服务端接口检查。

动态流程为 pending → published → 作者编辑回 pending → 管理员批准 → hidden → published → 软删除。评论流程为 visible → hidden → visible → 软删除，重复恢复409不产生成功审计。读取响应返回期间实际撤销 grant 后，客户端结束身份检查拒绝数据；后续读取和写入403。

后置核对一条动态及一条评论均软删除，动态正文为复审后内容、状态保留 published、最终审核人为管理员且原因“恢复公开”；评论正文、visible 状态、作者审核人及“评论恢复”原因匹配。七条 dynamic.changed.v1 pending Outbox 的 AggregateId/载荷精确对应，评论变更不额外追加动态事件。八条成功审核/删除审计的动作、原因、目标类型/编号与操作者快照逐条匹配，原数据断言保持，全部 Outbox 共43条。

最终运行和清理结果见[本仓证据](../validation/community-reads-20261103.json)。临时数据库和服务必须停止，端口关闭及口令文件移除另行核对。Node Cookie 适配不计浏览器 UI 验收，pending Outbox 不计 Kafka 成功投递。本轮未新增社区数据范围、客户端版本/幂等协议，也未处理尚待决的 D-49 / D-50 / D-09。真实浏览器/设备、供应商、存储、Kafka/容器、签名原生包与远程 CI 仍待验，未启动/重启 Docker。

# 收益完整读取与会话撤销 HTTP 核对

日期：2026-11-03。负责人：Backend。对应 API-R04 / ADM-24，保持 OpenAPI 1.51.1 / 143 操作与 24 迁移。后端仅更新验收夹具的场景计数及新增场景断言，生产接口与数据规则保持。

独立收益 HTTP 套件沿用编译 Nest、隔离 PostgreSQL 与前端生产恢复控制器。原八项覆盖单条写入响应丢失、原键恢复且不覆盖后续修改、账号隔离、CSV 部分成功和第25行后撤权、重复应用恢复不重写。本轮增加完整列表十字段及嵌套录入人投影、金额/备注、雪场和日期筛选、后续空页，以及读取响应返回期间实际退出管理员会话、结束身份核对拒绝旧内容、显式登录后恢复读取。

后置数据库继续要求两条单条请求、两项导入任务、30行导入记录、28条收益、29条逐行写审计、两条导入审计、两条仅含 jobId 的 pending Outbox。原金额2.34、备注later、27行成功/3行失败、未授权末行无写入和所有会话已撤销均保留核对。读取和退出会话不产生新增业务写入。

运行结果、原始日志摘要和临时服务清理证据见[当前报告](../validation/admin-revenue-20261103.json)，前端改动见[页面说明](../../../web/docs/engineering/admin-revenue-read-lifecycle.md)。额外复验现有管理 HTTP 套件，使用另一个全新临时数据库。

原恢复服务通过四次显式调用执行，不作为 Kafka/Inbox/定时器/租约到期验收。内存本机存储与 Node Cookie 不作为真实浏览器、CSRF、IndexedDB 或设备证据。本轮不启动或重启 Docker，不运行完整 Kafka；现存 Windows AccessDenied 故障保持。真实模型/Embedding/存储、容器、签名包和远程 CI 仍待验。D-49/D-50/D-09 未实施，整体项目未完成。

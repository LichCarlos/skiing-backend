# 全局雪场生产客户端 HTTP 与持久核对

日期：2026-11-03。沿用 API-M05 / OpenAPI 1.51.1。本轮后端生产业务与迁移保持，扩展 `scripts/admin-authorization-http-fixture.ts` 的后置断言。

Web 生产全局雪场读取、表单预检、保存和状态命令连接编译后的 Nest 服务及新临时 PostgreSQL。业务账号只绑定可配置角色，按 portal/grants 与 resort all 范围管理全局数据；创建与发布使用该业务账号，管理员修改评分、改归属、下架、再发布和软删除。字段目录仅返回有效读写策略，私有字段写入被拒；merchant 范围不能调用全局接口。读取响应期间真实撤销角色授权后，结束身份检查拒绝发布数据。

后置断言核对四条物理雪场记录，其中本轮新增全局雪场软删除且最终状态保留 published；归属改至第二个商家，票价288、评分4.8、评分人数99、介绍和授权字段精确匹配，封面/相册/标签为空。六条全局雪场 Outbox 的来源、商家和状态载荷逐条匹配，六条成功审计的动作与操作者精确匹配。原商家雪场八事件/八审计、原始两条雪场数据与收益隔离断言保持；雪场事件共15、全部 Outbox 共36。

最终运行状态、实际测试数、临时服务停止及端口清理以[本仓证据](../validation/global-resort-reads-20261103.json)为准。HTTP 使用 Node Cookie 适配，不能代替浏览器 UI 验收；Outbox 持久化不能证明 Kafka 投递。原生 Kafka Windows 文件删除失败尚未解决，本轮没有重试同一实验。没有启动/重启 Docker 或其 WSL 分发，也没有发布/推送。

客户端预读取不等于服务端版本条件或创建幂等。D-49 商家资料管理、D-50 生命周期原因及 D-09 注销仍待决；真实浏览器/设备、实际模型/Embedding/存储、容器/签名包和远程 CI 验收仍未完成。

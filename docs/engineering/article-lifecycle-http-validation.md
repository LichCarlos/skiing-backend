# 文章管理真实 HTTP 续验

日期：2026-11-03。负责人：Backend。本轮仅扩展验证夹具，生产业务代码、OpenAPI 1.51.1 / 143 操作及 24 项迁移保持。最终结果与日志摘要见[本仓证据](../validation/article-reads-20261103.json)。

运行方式沿用[管理授权 HTTP 验证](admin-authorization-http-validation.md)：在独立临时 PostgreSQL 中部署迁移、双次 seed、核对数据库，再启动编译 Nest；独立 Web 仓库运行生产客户端模型的真实接口测试。随机凭证只通过环境传入。客户端完成后，后置夹具检查持久化与服务停止状态；不启动 Next、Expo 或 Docker。

客户端复用迁移创建的文章分类字典，通过真实 API 新增启用分类项，以生产表单加载器、保存准备器和命令方法执行文章生命周期：草稿版本 1、发布版本 2、已发布内容编辑版本 3、撤回版本 4、再次发布版本 5、软删除版本 6。首次发布记录的时间在编辑、撤回、再次发布和删除后保持。已发布编辑保留 published，独立命令不携带正文或客户端 status。

普通业务账号通过可配置 grants 和 article 数据范围获得管理能力，未采用硬编码商家角色。self 仅返回本人文章，其他作者文章读取/修改 404；selected 可以读取指定文章，范围外 404，创建 403。实际数据返回之后撤销管理 grant，客户端结束身份复核拒绝发布该结果。本人文章由本人在 self 范围软删除，另一篇由系统管理员软删除。

后置验证要求两篇文章仍保留物理行及删除时间：管理员文章版本 6、状态 published、首次发布时间和作者保持；业务账号文章版本 2、状态 draft、发布时间 null、作者正确。分类、空封面及扩展字段均核对。八条 article.changed.v1 Outbox 保持 pending；按文章分别核对六条和两条状态事件，八条成功审计的动作、账号和归属匹配。新增分类项还有一条 dictionary.changed.v1 事件，独立核对其归属、状态和完整载荷；全套 Outbox 总数为原十三条加八条文章事件和一条分类事件，共二十二条，其他事件原有断言继续执行。

本轮不验证 Kafka、Inbox、模型/Embedding 供应商、对象存储、真实浏览器/设备或容器。D-49、D-50、D-09 保持未实施，整个项目尚未完成；Docker 和其 WSL 发行版不启动、不重启。

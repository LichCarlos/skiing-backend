# 本人资产读取与删除的当前授权

维护：Backend。日期：2026-11-04。范围：既有 API-ASSET-01 的 `GET /assets/:id` 与 `DELETE /assets/:id`。接口、DTO/VO、权限目录、依赖、数据库结构和 24 项迁移保持；OpenAPI 仍为 1.51.1 / 143 操作。

## 行为

本人读取使用既有 `asset:read-own`，本人删除使用 `asset:delete-own`。`AssetRepository.findOwnedReady` 的内部 operation 参数区分这两个操作，始终按认证账号 OwnerUserId 和 ready 状态过滤。仓储在 RepeatableRead 事务中重建当前账号、有效角色与显式 grant；不信任旧 Guard 结果，也不将管理入口、上传权限或商家身份作为附加条件。

读取先准备资产、调用实际签名器，再用第二个独立只读业务事务重新检查权限和同一 ready 对象。签名期间撤权返回 403；对象已删除或存储键改变返回 404，均不把旧签名放入 HTTP 响应。签名不放进数据库事务，不持锁等待外部工作。

删除先用 delete 操作准备本人对象，在独立 Serializable 提交事务中锁住 Asset，再重建 `asset:delete-own` 授权。只有 ready、本人、五类引用均为空才置为 deleted；事务拒绝时不会调用物理删除。数据库提交后继续完成原有 S3 删除，不因之后撤权而阻断已经授权提交的收尾；外部删除失败仍按既有 503 处理，不自动重试。

Serializable 事务可能在等待锁之前就建立旧快照。为避免漏掉等待期间新提交的头像、雪场封面/相册、文章封面或动态图片引用，持有 Asset 锁后另用当前已提交视图查询五类引用，仅增加否决条件。事务内仍保留完整引用过滤；该方式沿用已有管理员资产删除策略。绑定写入者须遵守已有 Asset 行锁规则。额外已提交查询需要可用数据库连接，失败会阻止删除，不把失败当作无引用。

## 验证

单测覆盖签名前拒绝、签名后撤权、签名后目标消失/换键、成功读前后复核、删除拒绝不调用 S3、删除操作独立于读取，以及 read-own/delete-own 不由 upload grant 替代。

执行 [Windows 原生隔离专项](native-storage-validation.md) `pnpm test:native-storage`，入口创建专用 PostgreSQL17/pgvector、MinIO、clamd；先运行 `test/assets.db-spec.ts`，再执行 `test/assets.storage-integration-spec.ts`，无需 Docker。

新增真实存储用例保留所有实际 Guard、Repository、Scanner、AWS SDK 和签名器。时序观察器在实际签名前或签名后提交权限变化，不伪造签名或对象结果；读取拒绝不返回 URL，原对象保持 ready。删除预读后分别停用账号、停用角色、解绑成员、删除 grant、停用权限目录，检查 403、ready 和真实对象字节保留、S3 DELETE 未调用。另验证读取期间执行真实本人删除，外层读取 404 且对象消失；仅 read-own 可读而不可删、仅 delete-own 可删而不可读，均无上传/管理入口要求。

新增数据库竞争用例用真实事务持有 Asset SHARE 锁，绑定本人头像后暂停；发起本人删除并通过 pg_stat_activity 观察实际锁等待，再释放绑定事务。删除必须 422，头像外键、ready 行及对象字节保留，不能用单纯顺序测试代替该竞争边界。此数据库回归使用存储端口夹具，物理 MinIO 断言来自前述真实存储专项。

最终结果、源码与三仓独立工程检查见[验收证据](../validation/owned-asset-access-20261104.json)。[上传事务授权](asset-upload-authorization.md)的既有 7 项在途撤权测试继续保留在同一真实存储套件中；旧 EICAR 独立扫描套件不计入本轮。

## 限制

双读不能撤销已经签发或曾交给调用方的 15 分钟能力 URL。真实测试刻意在签名观察器中捕获 URL 并确认它仍能下载，以区别“不返回新 URL”和“存储服务立即撤销能力”。签名后复核只覆盖其快照中的账号/权限与目标状态，不承诺消除最后复核之后的一切并发变更。事务建立后撤权的串行化顺序、请求开始后的会话注销规则保持。

生产 TLS/桶策略、签名密钥轮换、失败物理清理、容量/连接池、浏览器/设备与联合灾备仍待验。冲突和连接故障必须阻止删除，当前本人接口没有新增自动重试或新的冲突线协议；不能据专项通过宣称全项目完成。
